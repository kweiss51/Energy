## Overview

The Energy Course Platform is an online learning tool that focuses on delivering high-quality educational content related to energy topics. Our goal is to turn passive learners into engaged, successful students through a user-friendly interface and intuitive navigation.

## Features

- **Minimalist Interface**: A clean and distraction-free design that emphasizes content.
- **Intuitive Navigation**: Effortless user journey from homepage to course completion.
- **Fast Performance**: Quick loading times for videos and a frictionless payment process.
- **Data-Driven Insights**: Comprehensive analytics to track user behavior and improve the platform.

## Getting Started

To get started with the Energy Course Platform, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/energy-course-platform.git
   ```
2. Navigate to the project directory:
   ```
   cd energy-course-platform
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Open the `index.html` file in your browser to view the platform.
